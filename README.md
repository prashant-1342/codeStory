## 🌟 Overview

CodeStory connects to your GitHub account and turns your commit history into a rich, AI-powered developer profile. It analyzes what you build, when you code, and how you work — then surfaces that data through beautiful visualizations and a personalized **Coding Personality** generated by LLaMA 3.3 via Groq.

Think of it as your annual GitHub recap, available any time.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔐 **GitHub OAuth** | Secure sign-in with GitHub via NextAuth — read-only access, never modifies your code |
| 🤖 **AI Commit Summaries** | Weekly changelogs auto-generated from your commits using LLaMA 3.3 (Groq), cached in Supabase |
| 🧠 **Coding Personality** | AI-generated developer personality type based on your peak hours, active days & commit patterns |
| 📊 **Commit Activity Graph** | 30-day bar chart of your commit frequency per repo using Recharts |
| 📁 **Most Changed Files** | Ranked breakdown of the files you touch most across recent commits |
| 📈 **Repo Stats** | Additions, deletions, and total changes across your last 15 commits |
| 🗂️ **Repo Deep Dive** | Per-repository page with full commit history, stats, and AI summary |
| 💾 **Cached Summaries** | AI summaries are stored per-user per-repo per-week in Supabase — no repeat API calls |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- A [GitHub OAuth App](https://github.com/settings/developers)
- A [Groq API key](https://console.groq.com/)
- A [Supabase](https://supabase.com/) project

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/codestory.git
cd codestory

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
```

### Environment Variables

Create a `.env.local` file in the root:

```env
# GitHub OAuth (from https://github.com/settings/developers)
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret

# NextAuth
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your_random_secret_string

# Groq AI
GROQ_API_KEY=your_groq_api_key

# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
```

### Supabase Setup

Run this SQL in your Supabase dashboard to create the summaries cache table:

```sql
CREATE TABLE summaries (
  id SERIAL PRIMARY KEY,
  github_username TEXT NOT NULL,
  repo_name TEXT NOT NULL,
  summary TEXT NOT NULL,
  week_start DATE NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🤖 How the AI Works

### Commit Summarizer
Sends up to 20 recent commit messages to LLaMA 3.3 via Groq and receives a clean, categorized changelog:

```
🚀 Features — Added dark mode toggle
🐛 Bug Fixes — Fixed login redirect on expired session
♻️ Refactoring — Extracted auth logic into shared hook
```

Summaries are cached per user + repo + week in Supabase, so the AI is only called once per week per repo.

### Coding Personality
Analyzes commit timestamps across your top 5 repos to find your peak coding hour, most active day, and commit type breakdown (features vs. fixes vs. refactors). LLaMA 3.3 then generates a creative personality title and description like:

> **"The Midnight Architect"** — *You do your best work at 2am on Thursdays. Feature commits dominate your history — you're always building, rarely breaking.*
